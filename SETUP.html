1 Foundation

Name your calendars exactly right

Grid never reads a calendar's colour — it reads its name, and matches it against four words. A calendar called "Work Shifts" still works; one called "Job" does not, and its events quietly draw blue instead of their real colour. Grid Quick Add is stricter: it writes to an exact name, and a mismatch means the event silently goes nowhere.

WorkMatches work, shift, job → blue
CheerMatches cheer → pink
ClassesMatches class, school, course, lecture → green
PersonalAnything else → blue

In the Calendar app: Calendars → Edit → check each name character for character. If you still have a Habits calendar from before, leave it — its events just draw blue now.

2 Siri · part one

Teach Grid Quick Add to answer out loud

Siri runs a shortcut when you say its name, so the name is the phrase — there's no "Add to Siri" step to find. But the shortcut was written for typed input, and Siri has nothing to hand it. Right now, spoken, it runs on an empty sentence and stops.

Open the existing Grid Quick Add shortcut and put two actions at the very top, above Get Dates from Input:

  1. If — Shortcut Input has any value
    Then: Text → set to Shortcut Input
    Otherwise: Ask for Input → type Text, prompt What's the event?
  2. Set Variable — Sentence
    Value is the If result (Shortcut Result).

Then replace every later use of Shortcut Input with Sentence — in Get Dates from Input, in the Use Model prompt, and in the title Text action.

While you're in there: delete the Habits line from the model prompt and its Otherwise If branch. That category disappeared with the habit tracker, and an event filed there now just draws blue like any unrecognised calendar.

Typing in the app still works exactly as before — that path fills Shortcut Input, so the If takes the first branch and never asks.

Test it "Hey Siri, Grid Quick Add" → it asks what the event is → say dentist Thursday at two → the confirmation menu appears → tap Add. Open Calendar and check it landed on Personal, this coming Thursday, 2:00pm.
3 Siri · part two

Build Grid Todo

New shortcut. Name it exactly Grid Todo — that string is the Siri phrase, so a stray space or a capital breaks it and Siri answers "I don't have an app for that".

What you'll sayHey Siri, Grid Todo
  1. If — Shortcut Input has any value
    Then: Text → set to Shortcut Input
    Otherwise: Ask for Input → type Text, prompt What's on the list?
  2. Set Variable — Item
    Value is the If result.
  3. If — Item has any value / Otherwise: Stop Shortcut
    Siri hands back an empty string if you say nothing. Without this you get a blank row in the app.
  4. Get Dates from Input → Format Date
    Input Item, save as Due. Then Format Date with a Custom format of yyyy-MM-dd, saved as DueYmd.

    Apple's own date detector, the same engine that makes dates tappable in Mail. "pack cheer bag friday" lands on Friday. A sentence with no date in it leaves DueYmd empty and the server files it under today — which is what you want for "call mom".

  5. Get Contents of URL
    URLhttps://grid-sync.gabealvarez.workers.dev/todo
    MethodPOST
    Headerauthorization → Bearer YOUR_TOKEN — one space after Bearer
    Headercontent-type → application/json
    BodyJSON · text = Item (Text) · date = DueYmd (Text)
  6. Show Notification
    Title Added to Grid, body Item. With AirPods in, Speak Text reads better than a banner you won't see.

The item appears when you next open Grid, not instantly. A shortcut can't write to the app's storage — that's browser storage on your phone, with no way in. So the shortcut posts the one line to the server, and Grid drains that queue every time you open it or switch back to it. The signal it worked is the toast: 2 items from Siri.

Nothing gets overwritten by this. Each item is deleted from the server only once it's safely in the app, and it carries an id so a failed delete can't duplicate it.

Test all three "Hey Siri, Grid Todo" → buy poster board → open Grid, it's under today.
Again → pack cheer bag friday → it's on Friday, not today.
Again → say nothing → nothing is added, no error.
4 The widget

Replace the Scriptable script

This one earns its place twice: it's the home-screen view of today, and it's the only thing on the phone that can see your calendar and tell the app about it. Until it runs, the hour-by-hour day view has nothing to draw.

  1. Paste the new script in
    Scriptable → open your existing Grid script → select all → replace with the contents of widget/grid-widget.js from the repo.
  2. Run it once inside Scriptable
    It asks for the sync token and stores it in the iOS Keychain — not in the script file, which syncs through iCloud Drive and has a copy in a public repo.
  3. Set the widget to medium or large
    Long-press the home screen → the widget → Edit Widget, or remove and re-add at the right size. Small cannot work — iOS gives that size exactly one tap target for the whole widget, so per-row checkboxes are impossible. At small it shows the next event and a count, and tapping opens Grid.
  4. Open Grid and tap a day
    The hour grid should now have your events in it. If it's still empty, the widget hasn't run yet — run it by hand in Scriptable once more.

Tapping a checkbox flashes Scriptable open for about a second. That's not a bug and it can't be avoided: a home-screen widget runs no code when tapped, it can only open a URL. The box opens the script with a toggle parameter, which flips the item on the server and exits.

The widget may not redraw straight away either — iOS decides when widgets refresh. The tap landed; the picture is stale. The app reconciles the moment you next open it.

Test it Tap a to-do box on the widget, then open Grid. The item should be ticked. If it isn't, the token in the Keychain is wrong — run the script by hand in Scriptable and watch for a 401.
5 Optional

Build Grid Scan

The photo-of-a-schedule path: point it at a GroupMe screenshot and it reads every shift at once. This is the only part of Grid that costs money — roughly 4¢ a scan, so about 20¢ a month if you scan weekly.

It needs an Anthropic API key that you create and paste into the shortcut yourself. It never goes in the app or the repo. Full recipe in CAPTURE.md; set a $5/month spend limit in the console and forget about it.

Skip this if you enter shifts by hand. Everything else in Grid works without it — the Scan a Schedule button simply won't do anything until the shortcut exists.

Things that will never work, and why

Worth knowing so you don't spend an evening trying to fix them.

  • Grid can't read your calendar directly. iOS gives web apps no calendar access at all. Everything you see in the day view is a mirror the widget pushed, so it's as fresh as the widget's last run.
  • A widget tap can't happen silently. Widgets run no code. Every tickable box costs a one-second flash of Scriptable.
  • A small widget can't have checkboxes. One tap target per widget at that size, decided by iOS.
  • The widget won't redraw the instant you tap. Refresh timing belongs to iOS, not to the script.
  • A to-do never gets a time slot. That's the whole distinction: an event happens at an hour, a to-do happens some time that day. To-dos live in the Anytime column by design.
